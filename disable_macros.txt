MACROS AUSBLENDEN – vor dem Bauen der .exe
==========================================

Datei:  lib/features.js
        (im Projektordner: d4ovi\lib\features.js)

Dort stehen drei Schalter. 1 = drin, 0 = komplett raus:

  module.exports = {
    MACROS: 1,        // der ganze Reiter "Macros" – 0 schaltet auch beide unten ab

    LOCK: 1,          // Lock (Tasten halten oder im Takt drücken)
    CLICK_SPAM: 1,    // Click spam
  };


Was 0 bewirkt
-------------
MACROS: 0       Kein Reiter "Macros" in den Einstellungen, und der Hintergrund-Helfer
                (der Klicks und Tasten sendet) wird nie gestartet – egal was in den
                gespeicherten Einstellungen steht.

LOCK: 0         Die Karte "Lock" fehlt, Lock wird nie ausgeführt.
                Damit verschwindet auch die Karte "Character" (sie speichert nur die
                Lock-Tasten).
CLICK_SPAM: 0   Die Karte "Click spam" fehlt, click spam wird nie ausgeführt.

Stehen beide auf 0, ist es dasselbe wie MACROS: 0 (kein Reiter).


Beispiele
---------
Alles raus:                       MACROS: 0
Nur Click spam behalten:          LOCK: 0
Nur Lock behalten:                CLICK_SPAM: 0


Danach bauen
------------
  npm run dist

Die neue .exe liegt in dist\D4-Overlay-<version>-portable.exe.
Die Schalter werden in die .exe eingebaut – ändern danach geht nur durch neu bauen.
Gespeicherte Einstellungen (dist\D4-Overlay-Data) bleiben erhalten; schaltest du
etwas später wieder auf 1, sind die alten Tasten wieder da.
