MACROS – building with or without them
=====================================

The macros (lock, click spam) send input to the game. Blizzard's terms do not allow that,
so they are NOT in the .exe by default.

  npm run dist        .exe WITHOUT the macros   (the one to share / the download)
  npm run dist:m      .exe WITH the macros      (for yourself only, at your own risk)
  npm run start:m     run from source, with the macros

Without the macros there is no "Macros" tab in the settings, and the helper that sends
clicks and key presses is never started.

How it works: tools/dist.js writes the choice into lib/build-flags.json while building
(and deletes it again afterwards); lib/features.js reads it.
